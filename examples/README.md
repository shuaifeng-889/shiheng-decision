# 示例

三个可直接运行的处境向量，覆盖三类典型决策。用来验证安装、也用来学编码。

| 文件 | 场景 | 关键结构 |
|---|---|---|
| `01-negotiation.json` | 乙方被甲方要求先交完整方案再谈价 | 弱势 + 高赌注 + 低可逆 + 长期关系 |
| `02-career.json` | 在职跳槽：留下还是接受外部机会 | 均势 + 信息劣势 + 不可逆 |
| `03-team.json` | 空降管理者要不要处理不服管的老员工 | 均势 + 信息劣势 + 有第三方 |

`01-negotiation.matrix.json` 是配套的 2×2 收益矩阵，用于演示严格博弈求解。

---

## 怎么跑

```bash
# 完整报告
python scripts/cli.py decide -i examples/01-negotiation.json

# 只要结论
python scripts/cli.py decide -i examples/01-negotiation.json -f brief

# 带收益矩阵，做严格求解（看纳什均衡与 δ*）
python scripts/cli.py decide -i examples/01-negotiation.json \
    -m examples/01-negotiation.matrix.json --delta 0.55 -f brief
```

## 收益矩阵怎么填

```json
{
  "A": [[5, 1], [8, 2]],
  "B": [[5, 8], [1, 2]]
}
```

- `A` 是**对方（行）**的收益，`B` 是**我方（列）**的收益
- 索引含义：`[行][列]`

| 位置 | 含义 |
|---|---|
| `A[0][0]` | 双方都合作时，对方的收益 |
| `A[0][1]` | 对方合作、我方背叛时，对方的收益 |
| `A[1][0]` | 对方背叛、我方合作时，对方的收益 |
| `A[1][1]` | 双方都背叛时，对方的收益 |

**数字只表示相对大小，不必是真实金额。** 关键是顺序：

- 囚徒困境：`T > R > P > S`
- 斗鸡：`T > R > S > P`
- 猎鹿：`R > T > P > S` 且 `R > (T+S)/2`

`--delta` 是重复博弈的折现因子：你把"未来"看得多重。
`0.9` = 非常看重长期关系，`0.3` = 基本只在乎这一次。

## 这些示例不是标准答案

示例中的 `sv_tags` 是一种**可能的编码**，不是唯一正确的编码。

同一件事，如果你判断"谈崩了其实我也能承受"，`power_ratio` 就该填 `even` 而不是 `weak`，
结论会变。这不是错，这就是编码在起作用。

**用之前请按自己的实际情况重填，不要直接拿示例当结论。**
