# L0 处境编码字典（12 维 SV）

处境编码是整个模型精度上限的决定因素。**编码错了，后面四层全部失效。**

原则：能推断就推断，不能推断才问。向用户展示你推断出的完整向量并请求确认，
比逐条盘问更有效率，也更容易让用户发现你理解错的地方。

---

## 四个决定性维度（必须明确）

这四维错任何一个，整个推荐方向就错了。其余八维只在精度上有影响。

### 1. power_ratio — 相对实力

| 值 | 含义 | 判断依据 |
|---|---|---|
| `very_weak` | 悬殊劣势 | 对方可以承受与你彻底破裂，你不能 |
| `weak` | 劣势 | 正面冲突大概率会输，但对方也会付出代价 |
| `even` | 均势 | 谁也不能保证取胜 |
| `strong` | 优势 | 你有把握在正面冲突中占优 |
| `very_strong` | 绝对优势 | 结果基本确定，问题只剩代价 |

**提问话术**：「如果这件事谈崩了、彻底撕破脸，谁先扛不住？」

**常见误判**：把资源总量当实力。淝水之战（C027）中苻坚的算术没错——他确实人更多，
错在把一支多民族刚归附的军队当成单一意志的军队。**评估实力要乘以内部一致性系数。**

### 2. stakes — 赌注

`low`（可重试）/ `medium`（伤筋动骨可恢复）/ `high`（影响未来数年）/
`existential`（输了就没有下一次）。

**提问话术**：「这件事最坏的结果，是让你损失一笔钱，还是没有了以后？」

### 3. horizon — 博弈次数

`single` 一次性往后会各奔东西 / `repeated` 之后还要长期共处。

**这是被低估得最严重的一维。** 它决定信誉是否计息，从而决定一大批策略的合法性：

- `single`：空间大，一次性策略可用；
- `repeated`：所有依赖「对方不会识破」的信号类策略都要打折扣，
  因为一次性收益会被未来所有轮次的信任折价吃掉。

**提问话术**：「这件事结束之后，你和对方还需要再打交道吗？多久？」

### 4. reversibility — 可逆性（0..1）

0 = 做了就回不来；1 = 随时可以撤销。

**提问话术**：「做完之后如果后悔，撤销需要付出多大代价？」

判定锚点：

| 值 | 情形 |
|---|---|
| 0.0–0.2 | 签了合同、公开承诺、离职、结婚、投入不可回收的专用资产 |
| 0.3–0.5 | 换工作方向、重要投资、明确站队 |
| 0.6–0.8 | 一次谈话、一次报价、一次尝试性动作 |
| 0.9–1.0 | 发一封可撤回的邮件、做一次内部沟通 |

**交叉规则**：`existential` + 低可逆 + 依赖对方按预期反应 = 必须有退出预案，
否则那是赌博不是决策（引擎会自动在影子谏官里提示）。

## 八个精调维度

### 5. info_asym — 信息优势（-1..1）

正 = 你知情多于对方；负 = 对方知情多于你。

**注意反向的情况**：白登之围（C012）之前，刘邦连派十余批使者都说可以打，只有刘敬一人
说不能——而刘邦把刘敬囚了。**当所有输入信息的利益都同向时，输出的「共识」只是共同偏误。**
若 `info_asym ≤ -0.35`，引擎会强制提示检查反对意见通道。

### 6. time_pressure — 时间压力

`low` 可以耗 / `medium` 有窗口但不急 / `high` 必须在近期决定。

时间压力大时，所有依赖「等待」「消耗」「示弱」的策略（S04、S09、S27、S36）都会失效。

### 7. actors — 参与方数

2 或 3（含以上）。**一旦 ≥3，就必须换成联盟博弈的视角**：不再只看你与对手的收益表，
而要看是否存在可以借力或会被拉拢的第三方。

典型三方结构的失败模式是虞公（C004）：他以为自己只是通道、只赚服务费，
没看懂自己在对方收益表里的权重会随虢的存亡而变化。

### 8. third_party — 是否存在可借力的第三方

布尔。注意区分「存在第三方」与「第三方可用」——很多处境里有旁观者但没有利益相关的参与者。

### 9. resource_slack — 资源冗余

`low` 经不起消耗 / `medium` / `high` 可以打持久战。

**关键提醒（袁绍案例 C019）**：优势方的正确策略是消耗，不是决战——**占有进行时优势才应该选慢局**。
但前提是必须先验算双方的补给弹性。若对手的资源恢复速度快于你，拖延反而是自杀。

### 10. opponent_rationality — 对手类型

| 值 | 特征 | 影响 |
|---|---|---|
| `myopic` | 短视、容易被眼前利益引导 | 信号类、骄敌类策略成功率高 |
| `rational` | 理性、会算长期账 | 虚张声势容易被低成本戳穿 |
| `vindictive` | 记仇、以情绪而非收益行事 | **标准博弈模型失真**，需以其情绪目标函数重建 |

### 11. moral_constraint — 你可以承受的声誉与规则约束

`low` / `medium` / `high`。

这不是道德说教，而是**长期收益的计算项**：低约束在短期扩大策略集，长期会缩小愿意与你
合作的对象集合。引擎在 `moral_floor="high"` 时会对高危策略追加硬折扣。

### 12. 综合：多次 SLC 判定

若用户难以回答某维，可用替代问法：

- 判断 `power_ratio` → 「如果明天必须决出胜负，你赢的概率多大？」
- 判断 `horizon` → 「五年后你们还在同一个圈子里吗？」
- 判断 `reversibility` → 「有第三方见证或书面记录吗？」

## 编码自检（三层强制）

在把 SV 交给引擎之前，依次确认：

1. **四个决定性维度是否都明确？** 有任何一个处于「大概」状态就回去问。
2. **是否使用了对方的视角？** `power_ratio` 是相对值，不是自我感觉。
3. **是否有反向证据被忽略？** 若你能举出的所有证据都指向同一个结论，
   就要怀疑信息通道而非庆幸判断一致。
