# 史料陷阱与类比失真清单

这一类错误的共同特征是：**结论听起来深刻有力，且完全错误。**
本文件是给执行 Agent 的防呆手册，每次输出前对照。

---

## 一、演义当史实（最高频，也最致命）

以下流传极广的"典故"，**正史无据**：

| 常见说法 | 真实情况 |
|---|---|
| 诸葛亮空城计 | 《三国志》裴注引郭冲三事，**裴松之本人已辨其妄**。T3 |
| 蒋干盗书、周瑜反间 | 正史载蒋干见周瑜而还，未行反间。T3 |
| 献西施的美人计 | 《史记》无载，仅见《吴越春秋》《越绝书》等汉代晚期文献。T2–T3 |
| 周瑜打黄盖的苦肉 | 黄盖诈降并任火攻前锋属实（T1），「自受杖刑」无正史依据。T3 |
| 庞统献连环、赤壁锁战船 | 「船舰首尾相接」确载（T1），庞统献连环属虚构。T3 |
| 明修栈道暗度陈仓 | 正史仅载「从故道出陈仓」，八字中的前半属话本敷衍。T3 |
| 十面埋伏 | 后世评话敷演。T3 |
| 貂蝉 | 正史无其人。T3（原型是「布与卓侍婢私通」一句） |
| 薛仁贵瞒海渡辽 | 出自《薛仁贵征辽事略》，话本。T3 |

**纪律**：任何 T3 情节都不得作为决策推演的依据。可以当隐喻讲，
但必须明说是小说。这也是 `S31 美人计` 与 `S34 苦肉计` 在法典里刻意
**不配置 case_ids** 的原因——与其给它们找一堆演义当证据，不如留白。

真正站得住的空城计实例是 **C016 李广上郡遇匈奴**（《史记·李将军列传》T1），
它的成立条件是纯数学的：逃跑收益必为负，而和解鞍是敌方唯一无法解释为非害怕的姿态。

## 二、时代错置（anachronism）

把古代处境直接套现代组织，会抹掉根本的制度差异：

- **君主 ≠ CEO**。CEO 受公司法、董事会、劳动力市场约束，可被罢免、可被起诉；
  战国之君的权力靠人身依附、世袭与暴力垄断。**一旦用「职业经理人」想象古代之臣，
  「君要臣死」这层不对称就看不见了。**
- **封地 ≠ 部门**。封地是自筹武装的财政单位，部门不是。
- **盟约 ≠ 合同**。前者靠人质与婚姻维系，后者有第三方强制执行力。

**结果**：从一个不存在执行力保障的制度里学到的「盟友策略」，
搬到有合同法与诉讼的环境里，往往会给出「不用签约，用人情」的坏建议。

**防呆办法**：引用任何一条史案后，加一句「这条迁移到你的处境时，
要扣掉 X 的制度差异」。若扣完之后迁移价值所剩无几，就老实说这条不适用。

## 三、幸存者偏差

史书记录的都是被书写下来的决策，失败者的事迹常常未被系统记录，
即使记录下来也常被重写为「他性格有缺陷」。因此：

- 「某某用了这个计成功了」**不等于**这个计成功率高；
- 「某某因刚愎自用失败」**不等于**谨慎就能成功——大量谨慎者也失败了，
  只是他们不够有戏剧性。

**防呆办法**：本模型在每件成功案例旁强制写入 `counterfactual`（反事实）与
`failure_if`（失效条件），就是为了对抗这种叙事倾斜。**输出时不可省略反事实。**

## 四、叙事吸引力偏差

越是情节精彩、越是"神机妙算"的案例，越容易被反复引用，也越容易超出它真实的
代表性。孙膑、韩信、诸葛亮这三个人的案例密度远高于整个战国秦汉的平均水平——
他们是异常值，不是样本。

**防呆办法**：给用户的史案列表里，刻意保留**反面基准案例**。
本库配置了 8 条明确的反面基准，含 1 条正面基准（刻意保留，避免只会警告不会示范）：

- C019 袁绍不用田丰（销毁负反馈机制）
- C024 夷陵之战（情绪主导决策）
- C025 失街亭（关键岗位当作培养岗位）
- C027 淝水之战（把人数当战斗力）
- C028 哥舒翰出关（内部威胁大于外部威胁时，最优决策无法执行）
- C039 梁武帝纳侯景（用「机会难得」压倒专业判断，引狼入室）
- C041 北齐杀斛律光（敌国反间 + 自毁长城，与 C035 构成攻防两端）
- C045 隋炀帝三征高句丽（沉没成本升级）
- C049 隋灭陈（预警被系统性压下，信息通道堵塞）

**正面基准（唯一一条）**：

- C043 魏征谏诤与唐太宗纳谏 —— 补的是反面案例缺失的那一半。
  若只有「不听劝」的反面样本，模型就只会警告而不会示范。

## 五、模型自身的误用

| 误用 | 正确做法 |
|---|---|
| 把排序当成答案 | 排序是候选清单，失效条件才是裁决依据 |
| 处境契合度高就采信 | 先检查该策略的 `failure_conditions` 是否已成立 |
| 只看首推不计其余 | 影子谏官与自检环节必须输出 |
| 用本模型处理情感问题 | 情感需要的是支持，不是策略；本模型的适用对象是含对抗或取舍的决策 |
| 用本模型处理紧急安全事件 | 优先求助专业渠道（危机干预、报警、法律援助） |
| 声称算出了最优解 | 复旦 CCDA 已论证此类「非常规博弈」不存在完整数学均衡解；<br>本模型提供的是结构化类比 + 局部形式化验证，**不是最优解** |

## 六、每次输出前的最后一道门

问自己这三个问题，任一答不出就不要交付：

1. 我引用的每一条史案，标注了出处和 T1/T2/T3 等级吗？
2. 我给的建议里，有没有出现 T3 情节作为证据？
3. 如果用户的处境与我引用的史案在**制度背景**上差异巨大，我说明了吗？
