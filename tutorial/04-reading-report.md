# 04 · 读懂报告

**目标**：知道报告里哪些字能信、哪些要打问号，以及拿到报告之后该做的第一个动作是什么。

---

## 报告有六节

```
一、处境向量 (L0 ENCODE)     我如何理解你的局面 —— 第一个该核对的
二、博弈体检 (L2 VERIFY)     结构判定与数学结论 —— 唯一"硬"的部分
三、史案对标 (L1 RETRIEVE)   Top-5 典故 —— 类比，不是证明
四、策略排序 (L4 ARBITER)    六计打分表 —— 看相对排序，不看绝对分
五、影子谏官                  强制反驳 —— 最该认真读的一节
六、执行前三项自检            动手前的最后三问
```

---

## 核心区分：哪些是数学，哪些是类比

这是读这份报告最重要的一个认知。模型内部有两种性质完全不同的推理，混在一起输出，
但**可信度差一个量级**。

### 硬的部分（可证伪、可复算）

只有在**传入了 2×2 收益矩阵**时才出现：

| 输出 | 含义 | 可信度 |
|---|---|---|
| `收益参数 R/T/S/P` | 从你的矩阵读出的四元组 | 完全确定 |
| `纯策略均衡 [(1,1)]` | 枚举所有策略组合后找出的纳什均衡 | 数学结论 |
| `混合均衡 p=0.5` | 2×2 混合策略纳什均衡的闭式解 | 数学结论 |
| `先动溢价 / 承诺价值` | Stackelberg 序贯均衡与同时行动的差额 | 数学结论 |
| `δ* = 0.50` | 维持合作所需的最低折现因子 | 数学结论 |
| `Shapley 值 / 核非空` | 三方联盟的收益分配与稳定性 | 数学结论 |

这些全部在 `tests/test_nash_core.py` 里对照过解析真值（37 项断言）。**算错了会挂测试。**

### 软的部分（启发式，不可证伪）

| 输出 | 含义 | 可信度 |
|---|---|---|
| `相似度 91%` | 加权欧氏距离的归一化结果 | 取决于权重是否合理 |
| `推断原型：COALITION` | 由处境反推，没有收益矩阵时使用 | 类比 |
| `史案 Top-5` | 结构最接近的先例 | 类比，不是证明 |
| `策略综合分 0.652` | 三项加权 | 只用来排序，不含绝对意义 |

**权重是先验设定的**（`WEIGHTS` 里的数字是设计判断，不是学习得到的）。
所以「相似度 91%」不意味着「91% 确定」，它只意味着「在这套权重下，这条案例离你的处境最近」。

## 逐节怎么读

### 一、处境向量

**第一个动作：核对这一节，尤其是四个决定性维度。**

报告是你自己输入的回显，看起来没什么信息量——但它是整份报告的地基。
如果你发现某一维和你实际处境不符，**后面的全部内容作废，回去重填**。

引擎会提示缺维度：

```
提示：决定性维度未显式给出，已用默认值：power_ratio、stakes（结论可靠性下降，建议补全）
```

看到这行，就把报告当"参考"而非"依据"。

### 二、博弈体检

**这一节唯一需要你做的事：判断它给你的结构对不对。**

比如它说「囚徒困境，T>R>P>S」，你要问的是：**我的处境真的符合这个收益顺序吗？**

如果不符合——比如你其实无法真正惩罚对方（S 并不那么低），那它就不是囚徒困境，
而是别的结构。**收益顺序判断错了，数学再准也没用。**

有矩阵时的三个数字值得重点看：

- **`δ*`** 是"维持合作所需的最低耐心"。你的 `δ`（用了 `--delta` 传入）高于它，
  长期合作稳定；低于它，**背叛在数学上是理性的**——跟你人品无关。这是最实用的一项。
- **`承诺价值`** 为正，说明「公开自缚」有超额收益。典型做法是把不可逆的承诺当众做出
  （C037 寇准逼真宗渡河：渡河之后退路即断，全军知道没退路才会拼命）。
- **`先动溢价`** 为正，说明先手有价值，值得为抢先行动付出成本。

没矩阵时这一节是降级的：它会说"本节降级为由处境反推原型，性质是类比而非求解"。
这时候下面的「博弈契合度」一项可信度更低——**这是模型主动告知的降级，不是遗漏**。

### 三、史案对标

每一条史案包含：出处、可信度等级、决策点、行动、结果、**迁移**、**反事实**、**失效条件**。

**读这一节的方法不是"看谁像"，而是看「迁移」那一段里的机制是否在你的处境里成立。**

举个例子。C018 官渡·乌巢烧粮的迁移是：

> 当己方在兵力、粮草、时间三个维度都劣于对手时，不要在这三个维度上竞争，
> 而去切断把三者联系起来的那条链。

这个机制可以用在任何"多输入单输出"的困境上。但它成立有个前提：
**对手确实依赖你控制的那条链，且没有替代供给。** 这个前提就是它的失效条件。

**注意 `T1 / T2 / T3` 标记。** T3 是小说敷衍层（空城计、蒋干盗书、献西施、苦肉计细节），
**禁止作为决策依据**。案例库全部是 T1，但你在别处读到兵法故事时要自己查这一层。

**反事实必须读。** 只讲成功不讲代价的内容是有毒的。C044 石敬瑭割燕云的教训不是
"他坏"，而是"用不可逆资产换即时援助，代价由此后数百年、无数不相干的人承担"——
这个结构在今天的商业和个人决策里反复出现。

### 四、策略排序

```
score = 0.45 × 处境相似度 + 0.25 × 博弈契合度 − 0.30 × 风险折扣
```

**绝对分数没有意义。** 0.652 不代表"65.2% 的成功率"。它只用来排序。

**相邻两项差距小于 0.05 时，视为并列。** 0.652 与 0.603 之间的差别，远小于你编码时
一个维度的判断误差。不要因为差了 0.05 就认定第一优于第二。

真正需要区别对待的是**断档**：0.566 之后直接掉到 0.477，说明第一名明显更契合。

**风险折扣不为零时，要看清为什么。** 它来自三处：

- `redline` 里出现"高危/禁忌/违法/欺诈/违约"等词 → 扣 0.55
- 带 `evidence_warning`（史料支撑不足）→ 扣 0.15

也就是说，**风险折扣是模型在替你扣分，而不是在给你推荐**。看到扣了 0.55 还在榜上的策略，
基本可以判定：它在结构上很契合，但**用不了**。

### 五、影子谏官

**这一节是模型专门用来反驳前面内容的。它最该被认真读。**

触发条件包括：

- `horizon=repeated` 且首推是信号类/序贯类策略
- `stakes=existential` 且 `reversibility < 0.3`（高赌注 + 不可逆）
- `info_asym ≤ -0.35`（对方比你懂）
- `moral_constraint=low`
- `opponent_rationality=vindictive`
- 承诺价值过高
- 判定博弈可长期持续

没触发时它也会给你一句固定的话：

> 未触发结构性风险标记。仍需自问一句：你有可以当面告诉你「你错了」的人吗？

这不是凑数。C019 袁绍把田丰下狱之后，他失去的不是一个谋士，是**整个阵营的信息上达通道**，
此后所有决策都在错误信息上做出。

### 六、执行前三项自检

三个问题，按顺序回答：

1. **我的反对意见通道在哪里？** 最近一次听到"你这样不对"是什么时候？答不出来，
   说明这份报告的排序建立在你自己的自我认知上——而那正是最不可靠的输入。
2. **失效条件里有几条正在发生？** 回到首推策略的失效条件逐条对照。
   **已有任一条件成立，该策略此刻就不成立，无论它的分多高。**
3. **失败时我从哪里退出？** 动手前写下退出线与退出方式。不可逆 + 无预案 = 赌博。

---

## 拿到报告后的第一个动作

**不是执行首推策略。是去查它的失效条件。**

```bash
python scripts/cli.py stratagem --show S19
```

然后逐条对照：这一条的失效条件里，有几条已经在我身上成立了？

这是整个模型最反常识的设计：**它先帮你找到一个方案，再花同样的力气告诉你这个方案
在什么情况下不能用。** 而多数决策失败，不是没想到办法，是用了失效条件已经成立的旧办法。

---

## 什么时候该无视报告

四种情况，报告应当被丢弃：

1. **处境向量与你实际不符** —— 地基错了，上面全废
2. **博弈原型判断明显不对** —— 结构错了，数学再准也没用
3. **首推策略的失效条件已成立** —— 这是硬否决，不看分数
4. **史案相似度最高只有 60% 出头** —— 说明库里没有真正对得上的先例，
   这时候它给的类比是硬凑的，应当如实承认"没有先例"，而不是选一个最像的

第四条尤其重要。模型自己知道覆盖有限（50 条案例、22/24 部正史），
**命中率低时应该承认没命中，而不是把最不像的当成最像的用。**

---

## 一句话总结

> 二、四两节看"结构对不对"，三、五两节看"我是不是在骗自己"，六节看"我有没有退路"。
> 分数只用来排序，从来不用来做决定。
